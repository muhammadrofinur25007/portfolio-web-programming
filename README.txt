PORTOFOLIO UTS WEB PROGRAMMING - MUHAMMAD ROFI NUR FASYIH

Isi folder:
- index.html
- style.css
- script.js

CARA MENJALANKAN:
1. Ekstrak ZIP ke folder.
2. Pastikan ketiga file ada di folder yang sama.
3. Klik dua kali index.html atau buka melalui browser.
4. Internet dibutuhkan untuk memuat font Google; tanpa internet tetap menggunakan font fallback.

YANG PERLU DICEK/DISESUAIKAN SEBELUM DIKUMPULKAN:
- Ganti baris "Silakan sesuaikan nama sekolah" dengan riwayat pendidikan yang benar.
- Persentase skill hanya contoh; sesuaikan dengan kemampuan sebenarnya.
- Gambar profil adalah ilustrasi placeholder, bukan foto asli. Ganti bila dosen mengharuskan foto sendiri.
- Pastikan deskripsi proyek sesuai proyek yang benar-benar pernah dikerjakan.
- Form kontak hanya demonstrasi front-end: data tidak dikirim ke server/email.

CARA MEMBUAT PDF PENGUMPULAN:
1. Buka website di browser dan uji navigasi di desktop serta mode mobile (Developer Tools > Toggle device toolbar).
2. Ambil screenshot tampilan website (Home, Tentang, Skill, Project, Kontak).
3. Uji JavaScript: kirim form kosong untuk menunjukkan validasi; masukkan email salah; lalu isi seluruh kolom dengan email valid untuk menampilkan notifikasi berhasil dan ringkasan data. Screenshot hasil-hasil ini.
4. Buka Microsoft Word atau Google Docs.
5. Susun halaman: judul/identitas; screenshot website; screenshot validasi form dan hasil sukses; lalu lampirkan source code index.html, style.css, dan script.js secara lengkap.
6. Untuk source code, gunakan font Consolas/Courier New ukuran 8-9 pt, spasi tunggal, dan pemisah judul per file. Pastikan kode tidak terpotong.
7. Ekspor/unduh dokumen sebagai PDF.
8. Buka PDF yang dihasilkan dan cek semua halaman, screenshot, dan kode terbaca sebelum dikumpulkan.

Catatan: Tidak menggunakan framework CSS. Website menggunakan HTML5, CSS, dan JavaScript murni.
